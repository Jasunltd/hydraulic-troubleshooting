# Attribution for processed hydraulic sensor data

**Original dataset:** Helwig, Nikolai; Pignanelli, Eliseo; and
Schütze, Andreas. *Condition monitoring of hydraulic systems*,
UCI Machine Learning Repository, dataset 447 (2018 donation;
original analysis discussed in 2015 publication).

- Source: https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems
- DOI: https://doi.org/10.24432/C5CW21
- Upstream license: **CC BY 4.0**,
  https://creativecommons.org/licenses/by/4.0/

**Modification notice:** Files in this folder contain selected/derived
feature tables from the original 2,205 hydraulic-cycle sensor profiles,
including stable-cycle gating, calculated cycle summary features,
within-cycle sensor window summaries, matched conditions, deterministic
development/holdout splits and pump nuisance-condition analysis.
They are not the UCI project's original raw sensor stream files.

original dataset/derived measurements**.
