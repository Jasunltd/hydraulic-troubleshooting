# Verification Receipts

This directory stores durable identities for executed research verification.

Current receipts:
- `primary-analysis-receipt.json` — exact primary Python analysis identity, public source ZIP identity, and derived-output hashes;
- `pump-leak-rule-receipt.json` — exact secondary nuisance-holdout analysis identity and derived-output hashes;
- `bounded-signal-discovery-closure-v1.json` — bounded scope closure, seam-test results, and explicit non-claims.

Superseded pre-namespace receipts were removed during closure so canonical state cannot silently point at stale code identities.

A receipt records **what was executed and what files were observed**. It carries no equipment authority and does not convert an engineering interpretation into field truth or operational benefit.
